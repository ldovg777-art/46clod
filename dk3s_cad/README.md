# Чертёж датчика концентрации ДК-3С-210АВ на AutoLISP (nanoCAD)

`dk3s_drawing.lsp` строит чертёж общего вида датчика ДК-3С-210АВ: формат А3, масштаб 1:2,
рамка и основная надпись по ГОСТ 2.104 (форма 1), главный вид с размерами и выносками,
выносной элемент А (2:1) с узлом рабочего электрода, технические требования.

Результат прогона через проверочный интерпретатор (без CAD): `dk3s_drawing.dxf` и `dk3s_preview.png`.

## Запуск в nanoCAD

Интерактивно:

1. Открыть новый документ (шаблон с миллиметрами).
2. Команда `APPLOAD` (или `_.APPLOAD`), выбрать `dk3s_drawing.lsp`. Альтернатива в командной строке:
   `(load "C:/путь/к/dk3s_drawing.lsp")`.
3. Команда `DK3S`. В командной строке появится `DK3S: drawing complete, entities: 454, dims: entmake, ...`.
4. Сохранить как DWG.

Пакетно (без окна): `dk3s_build.bat` ищет `nCad.exe` в `%ProgramFiles%\Nanosoft\*` и запускает
`nCad.exe -invisible -s dk3s_build.scr`. Скрипт грузит LISP, выполняет `DK3S`, сохраняет `dk3s_drawing.dwg`
и закрывает nanoCAD. Подсказки команды `SAVEAS` в разных версиях nanoCAD различаются: если DWG не создался,
поправьте две строки после `_.SAVEAS` в `dk3s_build.scr` или сохраните интерактивно.

Код совместим с AutoCAD, BricsCAD, ZWCAD: только `entmake`, без ActiveX и DCL.

## Как устроен файл

| Раздел | Что содержит |
|---|---|
| 1. Таблица параметров | все размеры датчика и листа в `setq`-переменных `g_dk3s_*`, мм |
| 2. Служебные переменные | имена слоёв, стилей, текущее начало и масштаб вида |
| 3. Примитивы | `dk3s_line`, `dk3s_arc`, `dk3s_pline`, `dk3s_text`, `dk3s_ellipse`, штриховка линиями |
| 4. Таблицы | слои, тип линии осевой, текстовый стиль, размерный стиль |
| 5. Размеры и выноски | `dk3s_dim` (entmake DIMENSION, при отказе - команда DIMLINEAR), `dk3s_leader` |
| 6. Рамка и штамп | А3, поля 20/5, форма 1 (185x55) |
| 7. Главный вид | скоба, наконечник, гильза с перфорацией, корпус M42x3, фланец, S46/S36, бирка, мостики, электроды сравнения |
| 8. Выносной элемент А | защитная трубка Ø6, токоотвод Ø3, наконечник S6,35, электрод Ø1,4 с выступом 2 мм |
| 9. Размеры и ТТ | размерные цепи главного вида, выноски, технические требования |
| 10. Команда `DK3S` | стадии INIT, TABLES, FRAME, MAIN, DIMS, LABELS, DETAIL, NOTES, DONE; при ошибке печатается стадия |

Всё строится в пространстве модели: датчик в масштабе 1:1, рамка и надписи увеличены в 2 раза
(`g_dk3s_scale_den`). Печать листа с масштабом 1:2 даёт А3. Размеры показывают истинные значения.

Правка размеров: только раздел 1. Осевые станции заданы абсолютно (`g_dk3s_z_*`, от вершины скобы),
диаметры отдельно. Обозначение документа и фамилии в штампе: `g_dk3s_designation`, `g_dk3s_author`, `g_dk3s_checker`.

## Кириллица

Русские строки в `.lsp` записаны кодами `\\U+XXXX`: так текст верно рисуется независимо от кодировки файла
и локали Windows (nanoCAD читает `.lsp` в ANSI, cp1251). Комментарии в UTF-8, на выполнение не влияют.
Чтобы править тексты: `python3 tools/lisp_cyr_escape.py --decode dk3s_drawing.lsp > src.lsp`,
отредактировать, затем `python3 tools/lisp_cyr_escape.py src.lsp > dk3s_drawing.lsp`.

Шрифт надписей `ISOCPEUR.ttf` (`g_dk3s_font`). Если его нет, CAD подставит шрифт по умолчанию; можно указать `arial.ttf`.

## Запасные пути (на случай отличий LISP в nanoCAD)

- `entmake` слоя не прошёл - слой создаётся командой `-LAYER`.
- `entmake` типа линии не прошёл - осевые рисуются сплошными.
- `entmake` текстового стиля не прошёл - используется `Standard`.
- `entmake` размерного стиля или размера не прошёл - переменные DIM* выставляются `setvar`,
  размеры ставятся командой `DIMLINEAR` (переключение автоматическое, режим печатается в итоге).

Все четыре пути проверены на интерпретаторе (`--fail DIMENSION,DIMSTYLE`, `--fail LAYER,LTYPE,STYLE`).

## Проверка без CAD

`tools/lispcheck/autolisp_mini.py` - интерпретатор подмножества AutoLISP (reader, динамическая область
видимости, defun, списки, строки, арифметика как в AutoLISP, `entmake` в ezdxf, `tblsearch`, `getvar`/`setvar`,
`command` для ZOOM, -LAYER, DIMLINEAR). `tools/lispcheck/run_dk3s.py` прогоняет чертёж и пишет DXF + PNG:

```
pip install ezdxf matplotlib
python3 tools/lispcheck/run_dk3s.py --out out            # DXF + PNG
python3 tools/lispcheck/run_dk3s.py --fail DIMENSION     # проверка запасного пути
```

Интерпретатор ловит ошибки синтаксиса, арности, неопределённые символы и логику геометрии,
но не заменяет прогон в nanoCAD: поведение `entmake` для DIMENSION/DIMSTYLE и подсказки `SAVEAS`
надо подтвердить на реальной системе один раз.
